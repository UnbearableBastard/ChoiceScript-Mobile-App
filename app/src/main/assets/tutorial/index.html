ChoiceScript Beginners Tutorial

Part 1: What Is ChoiceScript?

ChoiceScript is a programming language used for creating interactive stories. Its very easy to learn with no coding experience. You write as you normally would, add a few commands, and the player chooses what happens next.

This tutorial will go over the basics to get you started. It's recommended to also check out the tutorials on the Choice of Games Website as that goes into more detail.

*label Beginnings
You wake up in a dark room.

*choice
    #Try to find a way out.
        You stumble around in the dark, completely clueless as to where you're going until to suddenly stand on something sharp.
    # Stay still.
        You don't move a muscle, and instead you wait quietly and listen for anything to clue you in as to where you are.

In this tutorial, you'll learn how to:

  • Create your first project
  • Write choices
  • Track stats like health or gold
  • Use *if and *else for branching
