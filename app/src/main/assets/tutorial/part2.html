Part 2: The Basics & Indentation

A ChoiceScript story is made of text files. The most important ones are:

startup.txt – this is where you create and store your variables, some authors even start the game here.

*create - this command creates the variable. E.g: health, gold, gender or race.

choicescript_stats.txt – controls the stats screen. Any information you want to player to have access to goes here. Examples are character customization, world-building lore. Anything really.

Other scene files – Think of these as chapters in a book. They can be called anything you want, however they are case sensitive when it comes to running the game. The file name under scene_list must match the actual file name.

Indentation (spaces) is important

ChoiceScript uses spaces for structure. You can use either 2 spaces or 4 spaces but never both. For example:

*choice
  #Wave hello.
    You wave.
  #Say nothing.
    You stare at the ground.
Or: 
*choice
    #Wave hello.
        You wave.
    #Say nothing.
        You stare at the ground.
Never this: 
*choice
    #Wave hello.
        You wave
  #Say nothing.
    You stare at the ground.

Each # option is indented under *choice and the text under # is indented further.

This editor has increase & decrease indent buttons and uses 4 spaces. If you use this feature, then the rest of your code should be the same for a consistent structure.
