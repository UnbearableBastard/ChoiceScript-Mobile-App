Part 6: Scenes & *scene_list

As your story grows, you'll need to split it up into multiple scene files.

Examples:

startup.txt – create the variables & where the game begins.

chapter1.txt

chapter2.txt

ending.txt

*scene_list

In startup.txt, you tell ChoiceScript which scenes exist and in what order:

*title (Your story's name)
*author (Your name)

*scene_list
    startup
    chapter1
    chapter2
    ending

*label start
Welcome to the game!
*finish

Each line after *scene_list is the name of a .txt file (without the .txt).

ChoiceScript will look for files like chapter1.txt in your scenes folder. It's case sensitive, so make sure its spelt correctly.

Moving to the next scene: *finish

At the end of a scene, you can use *finish to jump to the next file in *scene_list:

You scream as you take an arrow to the knee and pass out.

*finish

If you are in startup.txt, *finish will move to chapter1.txt. Its best to have them listed in order.

Jumping directly to another scene: *goto_scene

If you want to skip to a specific scene, use *goto_scene:

*goto_scene ending

This jumps straight to ending.txt, ignoring the *scene_list order.

When to make a new scene file

Some reasons to create a new scene file:

A new chapter.

A death/endgame scene

To keep individual files smaller and easier to manage.
