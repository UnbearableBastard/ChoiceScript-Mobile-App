# ChoiceScript-Mobile-App
This is a custom Android ChoiceScript editor. Write, code, run and compile your games into .html files directly from your phone.

List of features:

Real-time ChoiceScript syntax highlighting, autocomplete and auto-indentation for commands.

Adjustable text zoom, up to 36sp.

The editor has a bottom bar with the following buttons: Undo/redo, in/decrease indent, search, bold/italic and a save button.

An error checker using the official ChoiceScript engine, along with accurate error messages. Can be use inside the editor and from the project menu.

Multiple themes: Classic, Dark, Solarized, Nord, Monokai, and Dracula, all with full syntax recoloring.

An offline spell checker using Harper.

Saving is automatic and can also be done manually.

A tutorial section is included for those who are new to ChoiceScript.

Test your games directly from within the app.

This project uses the official ChoiceScript engine (scene.js, choicescript/web/ assets) for error validation, running and compiling the game.
